# 🎮 俄羅斯方塊 - 網頁版

經典俄羅斯方塊遊戲，支援電腦和手機瀏覽器遊玩。

## 遊戲特色

### 🎯 虛擬搖桿控制
- **左右搖動** → 移動方塊
- **向上搖動** → 旋轉方塊  
- **向下用力搖** → 硬降（直接落底）
- 支援連續移動（停留觸發自動重複）

### 🎮 按鈕操作
- **↻ 旋轉按鈕** → 旋轉方塊
- **⬇ 硬降按鈕** → 瞬間落底
- **❚❚ 暫停按鈕** → 暫停/繼續

### 📱 跨平台支援
- ✅ Windows / macOS / Linux 瀏覽器
- ✅ Android 手機瀏覽器
- ✅ iPhone / iPad Safari
- ✅ 支援 PWA 安裝

## 快速開始

### 方法一：直接在瀏覽器開啟

```bash
# 開啟遊戲檔案
file:///C:/Users/ajleong/.hermes/workspace/tetris_game/www/index.html
```

或直接點擊瀏覽器開啟 `www/index.html`

### 方法二：本地伺服器（推薦）

```bash
# 使用 Python 啟動簡易伺服器
cd C:\Users\ajleong\.hermes\workspace\tetris_game\www
python -m http.server 8080
```

然後在瀏覽器開啟：`http://localhost:8080`

### 方法三：手機瀏覽

1. 將 `www` 資料夾傳輸到手機
2. 使用檔案管理器開啟 `index.html`
3. 或使用本地伺服器 + 手機連線到同一 WiFi

## 遊戲規則

| 操作 | 搖桿 | 按鈕 | 鍵盤 |
|------|------|------|------|
| 左移 | 向左搖 | - | ← |
| 右移 | 向右搖 | - | → |
| 旋轉 | 向上搖 | ↻ | ↑ |
| 硬降 | 向下用力搖 | ⬇ | ↓ / 空白 |
| 暫停 | - | ❚❚ | P |

### 評分系統
- 1 行：100 分 × 等級
- 2 行：300 分 × 等級
- 3 行：500 分 × 等級
- 4 行：800 分 × 等級
- 硬降每格：2 分

### 等級系統
- 每消除 10 行升級
- 等級越高，下落速度越快
- 最低間隔：100ms

## PWA 安裝（可選）

在手機瀏覽器開啟後：

**Android (Chrome):**
1. 點擊選單（⋮）
2. 選擇「新增至主畫面」
3. 遊戲會像原生 App 一樣出現在桌面

**iOS (Safari):**
1. 點擊分享按鈕（↑）
2. 選擇「加入到主螢幕」
3. 遊戲會像原生 App 一樣出現在桌面

## 常見問題

### Q: 手機上搖桿不靈敏？
A: 確保：
1. 使用現代瀏覽器（Chrome/Safari）
2. 不要縮放頁面
3. 清除瀏覽器快取後重試

### Q: 如何全屏遊玩？
A: 
- 電腦：按 F11 進入全螢幕
- 手機：安裝 PWA 後可全螢幕操作

### Q: 可以修改遊戲嗎？
A: 可以！所有原始碼都在 `www/index.html`，使用任何文字編輯器即可修改。
